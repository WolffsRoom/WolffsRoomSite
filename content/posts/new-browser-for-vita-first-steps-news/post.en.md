**Hey everyone! Wolff here!**

Democracy has spoken: **New Browser for Vita** won the poll, so I've already gotten to work! And what better place to start than one of the internet's most iconic sites? **Wikipedia** already loads in the emulator, complete with its logo, language options, and search box!

## App name

I haven't decided on a name yet, and I'm open to suggestions! Some people on Discord suggested **“Firewolff”**. I'm still on the fence, haha, but I have to admit the pun is pretty good.

## What's working so far

I've managed to adapt **Cobalt 27** (based on **Chromium M138**), the latest version. It's a huge leap from the Cobalt 25 I used for YouTube TV, with a much more modern web engine.

## What's still missing

- Fix a few graphics issues, particularly image transparency;
- Improve performance, since pages still take quite a while to load;
- Build the browser UI: address bar, tabs, and the Vita's native keyboard for text fields;
- Test on real PS Vita hardware (so far, everything has been tested in **Vita3K**).

More updates soon!

**Cheers!**
