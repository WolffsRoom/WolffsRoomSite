Unofficial PS Vita port of the Pizza Tower demo released at the 2019 Sonic Amateur Games Expo (SAGE). The demo is free and made in GameMaker.

## About the demo
- Released during SAGE 2019, with new levels, the Snick Challenge mode and plenty of unused content
- Snick the Porcupine is playable only in this demo
- Pizza coins drop from blocks and buy the shotgun at the Pizzamart

## Installation
- Download the [VPK](https://drive.google.com/file/d/1EgVvq6LYAK5bxLwH1CLnedn7eMGqDFZ9/view?usp=sharing) and install it with VitaShell
- Download the [data](https://drive.google.com/file/d/1CBof60EExpF4IrZMhyix6CvRicqSONRA/view?usp=sharing), extract the .zip and copy the extracted folder to ux0:data/
- Start the game from the LiveArea

## Requirements
- Hacked PS Vita
- kubridge.suprx plugin
- libshacccg.suprx
- game-data folder in ux0:data/ (from the Download data button)
