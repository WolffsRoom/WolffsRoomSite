File Manager Vita is an improved fork of VitaShell (by TheFloW) focused on usability. It has its own Title ID and a dedicated folder at ux0:FMVita/, so it can be installed side by side with VitaShell or another manager.

## Highlights
- Extended touchscreen support
- Animated backgrounds and themes, including a Custom theme via colors.txt
- Grid, 2-column and 3-column layouts
- Install several VPKs in a row
- FTP server with 0–100% progress
- Image viewer
- Undo system

## Installation
- Transfer the FMVita .vpk to the console (FTP or USB)
- Install it with VitaShell or another manager
