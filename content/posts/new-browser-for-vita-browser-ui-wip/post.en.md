Hey everyone! Wolff here!

The new browser has come a long way since the first steps! **It's no longer just a page on screen:** it now feels like an actual browser.

## What's new

- **Address bar** at the top with back, forward, reload, and a tab counter. Just tap it and type a URL or a search using the Vita's native keyboard.
- **New Tab page** with Google search and your most visited sites.
- **Tabs, history, downloads, and settings**, all with a Chrome-style UI.
- **Cursor mode** and PlayStation button prompts.
- **Video playback now works in the emulator!**
- **Better memory handling**, so heavier pages crash less often.

## Real hardware

I've started testing on a **real PS Vita**! The first builds closed right at launch, but thanks to the crash logs I've already fixed two of those issues.

There's still a lot to test on the console itself.

## What's still missing

- Improve performance and memory usage on heavier sites.
- Keep testing and fixing things on real hardware.

The **name is still open**, so keep the suggestions coming!

More updates soon!

Cheers!
