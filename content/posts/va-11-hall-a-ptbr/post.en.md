*VA-11 HALL-A: Cyberpunk Bartender Action* is a cyberpunk visual novel about mixing drinks and getting to know your customers.

## About this translation

This PS Vita port adapts CoffeLordran's original Brazilian Portuguese PC translation to the USA build **PCSE00756**, incorporating Spanish Vita localization work to improve accented glyphs and adjusting text wrapping and graphics.

## Translation status

The patch is available, though some minor line breaks and proofreading are still being reviewed.

## Installation

- The USA PS Vita game **PCSE00756** and an enabled **rePatch** plugin are required.
- Extract the ZIP using password **wolffsroom**.
- Place the PCSE00756 folder at **ux0:rePatch/PCSE00756/**. Game assets must be under **games/**.
- Restart the console if rePatch is newly installed.
- The Vita Store offers one **Install translation** button, with multiple mirrors as fallback downloads.
