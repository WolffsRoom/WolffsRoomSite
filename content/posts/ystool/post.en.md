A Python tool for translating Ys Origins on PS Vita, with a visual editing interface and a character counter so no line goes over its limit. The code will be published on GitHub once it is stable.

## Components
- Python backend: reading, saving and protecting the files
- VS Code-style HTML/JS frontend with a character counter
- PyWebview packages everything as a desktop app
