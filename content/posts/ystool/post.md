Ferramenta em Python para traduzir Ys Origins no PS Vita, com interface visual de edição e contagem de caracteres para não estourar o limite de cada linha. O código vai para o GitHub quando estiver estável.

## Componentes

- Backend em Python: leitura, salvamento e proteção dos arquivos
- Frontend em HTML/JS no estilo VS Code, com contador de caracteres
- PyWebview empacota tudo como app de desktop
