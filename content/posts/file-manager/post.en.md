File Manager is a file explorer designed specifically for PS Vita. Its new interface uses ScePaf, the framework behind the system applications, to provide native widgets, sounds, transitions and dialogs.

## In development
- There is no public release available for download yet
- The project is under development and should be tested carefully when a public build becomes available
- Its own Title ID will allow installation alongside VitaShell and FMVita

## Planned and testing features
- Copy, move, delete, rename and create folders
- Image, text, audio and video previews
- VPK inspection and installation
- FTP, search, multi-selection and touch support
- Themes, custom backgrounds and Portuguese/English interfaces
