File Manager é um explorador de arquivos criado especialmente para o PS Vita. A nova interface usa ScePaf, o mesmo framework dos aplicativos do sistema, para oferecer widgets, sons, transições e diálogos nativos.

## Em desenvolvimento

- Ainda não há uma release pública para download
- O projeto está em desenvolvimento e deve ser testado com cautela quando uma versão pública estiver disponível
- O Title ID próprio permitirá instalação ao lado do VitaShell e do FMVita

## Recursos planejados e em teste

- Copiar, mover, excluir, renomear e criar pastas
- Visualização de imagens, textos, áudio e vídeos
- Instalação e inspeção de VPKs
- FTP, pesquisa, seleção múltipla e suporte a toque
- Temas, fundos personalizados e interface em português e inglês
