Hey everyone! Following up on the latest news, I've started **rebuilding the Hollow Knight Nintendo 3DS port**, originally developed by **silviognotti**, to create a version adapted for **PlayStation Vita**.

The goal is to make it run on Vita **without relying on the 3DS's second screen**, which an emulator would otherwise have to handle. I'm also optimizing the controls and reimplementing elements from the PC/Steam version, such as **higher-quality textures** and a **single-screen interface**.

The project is still a work in progress, but **it's already playable on a real PS Vita**!

Because of the extensive optimizations silviognotti made to get the game running on 3DS, this version currently has **more missing textures and visually broken environments** than **PatnosD's port**. I'll keep working on those issues and share more progress — or perhaps even a **beta build for testing and first impressions**.

**The main goal isn't to create a 1:1 version of Hollow Knight.** Instead, I want a version optimized for the console, **targeting 60 FPS**.

Anyway, I'll share more as soon as I have something new to show.

Cheers, everyone!
