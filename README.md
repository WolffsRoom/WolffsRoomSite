# Wolff's Room

Site de projetos do Wolff's Room: ports, ferramentas, traduções e reviews para PlayStation Vita.

Site publicado: https://wolffsroom.github.io/WolffsRoomSite/

## Estrutura

- `index.html` — página única. Cada categoria e cada post é uma tela, com link direto pelo endereço (`#traducoes`, `#void`, `#wolf`...).
- `assets/` — capas, capturas de tela e elementos gráficos em pixel art.
- `.github/workflows/pages.yml` — publica no GitHub Pages a cada push na `main`.

Os jogos, marcas e artes pertencem aos seus respectivos donos. Ports e traduções são projetos de fã, não oficiais.
